# Cosmevo Cosmeceuticals

A modern, responsive e-commerce web application for Cosmevo Cosmeceuticals, built with Next.js, Tailwind CSS, and React.

## Features
- **App Router**: Utilizes Next.js App Router for optimal performance.
- **Custom Animations**: Smooth page reveals natively utilizing IntersectionObserver, along with custom requestAnimationFrame cursors.
- **Dynamic Cart**: Context-based cart state management.
- **Static to React**: Fully converted from a static HTML site into a modular, maintainable React application.

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build

```bash
# Create production build
npm run build

# Start production server
npm start
```
